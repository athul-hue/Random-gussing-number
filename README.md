# 🎯 Random Number Guessing Game

A simple Java-based number guessing game where players try to guess a randomly generated number. This project demonstrates core Java programming concepts and basic game logic.

## 📌 About the Project

The Random Number Guessing Game is a beginner-friendly Java project designed to practice programming fundamentals through an interactive guessing game.

## ✨ Features

- 🎲 Random number generation
- ⌨️ User input for guesses
- 🔍 Comparison between the guess and the target number
- 📈 Feedback to help the player guess correctly, if implemented
- 🔁 Multiple attempts, if supported by the program

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts:** Random number generation, conditional statements, loops, and user input

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/athul-hue/Random-gussing-number.git
cd Random-gussing-number
```

### 2. Check Java installation

```bash
java -version
javac -version
```

Install a JDK if Java is not already installed.

### 3. Compile and run

Replace `Main.java` with the actual Java filename in your repository.

```bash
javac Main.java
java Main
```
